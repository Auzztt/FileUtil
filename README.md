========================================
    文件批量重命名工具 - 使用说明
========================================

【工具简介】

这是一个功能强大的批量文件重命名工具，支持：
✅ 正则表达式筛选文件
✅ 多种重命名规则（查找替换、添加前缀/后缀、序号填充、修改扩展名）
✅ 预览重命名效果
✅ 多步撤销操作
✅ 进度条显示

【系统要求】

Windows 7 / 8 / 10 / 11 操作系统

【首次使用前的准备】

如果你的电脑已经安装过 Java，可以直接运行。
如果不确定，请按以下步骤检查：

第1步：检查是否已安装 Java
----------------------------------------
按下键盘的 Win + R 键
输入 cmd 并回车
在黑窗口中输入：java -version
按回车

- 如果显示版本号（如 java version "21"），说明已安装，可以直接使用
- 如果显示“不是内部或外部命令”，说明需要安装 Java

第2步：安装 Java（如需要）
----------------------------------------
1. 打开浏览器，搜索“JDK 21 下载”
2. 进入 Oracle 官网或华为镜像站
3. 下载 Windows x64 Installer（约150MB）
4. 双击安装，一路点击“下一步”
5. 使用默认安装路径即可

第3步：验证安装
----------------------------------------
安装完成后，重新打开 cmd 窗口
再次输入 java -version
看到版本号即表示安装成功

【如何使用】

1. 双击运行“文件批量重命名工具.exe”

2. 选择文件夹
   - 点击“选择文件夹”按钮
   - 找到你要处理的文件夹

3. 筛选文件（可选）
   - 在“文件筛选”框中输入正则表达式
   - 例如：^测试.*  表示只显示以“测试”开头的文件
   - 点击“应用筛选”
   - 点击“正则帮助”可以查看更多示例

4. 选择重命名规则
   - 从下拉框选择规则（查找替换、添加前缀等）
   - 输入规则参数

5. 预览效果
   - 点击“预览重命名”
   - 右侧会显示原文件名 → 新文件名

6. 执行重命名
   - 确认预览无误后，点击“执行重命名”
   - 在确认对话框中点击“是”

7. 撤销操作（如果需要）
   - 点击“撤销上次重命名”
   - 可以选择撤销1步、2步、3步或全部


【正则表达式常用示例】

输入以下内容可以筛选文件：

^测试.*        → 以“测试”开头的文件
.*\.txt$       → 以.txt结尾的文件
.*照片.*       → 文件名中包含“照片”
^[0-9].*       → 以数字开头的文件
.*\.(jpg|png)$ → jpg或png图片文件

【重命名规则说明】

1. 查找替换：将文件名中的指定文字替换成其他文字
2. 添加前缀：在文件名最前面添加文字
3. 添加后缀：在扩展名之前添加文字
4. 序号填充：在文件名前添加序号（如001_、002_）
5. 修改扩展名：批量更改文件后缀（如txt改成bak）

【常见问题】

Q: 双击 exe 没反应？
A: 可能是 Java 未安装或安装不完整，请按上面的步骤安装 Java

Q: 筛选后没有文件显示？
A: 检查正则表达式是否正确，点击“正则帮助”查看示例

Q: 重命名失败了怎么办？
A: 点击“撤销上次重命名”可以恢复文件原名

Q: 能处理子文件夹里的文件吗？
A: 当前版本只处理选中的文件夹，不包含子文件夹

【文件说明】

文件批量重命名工具.exe  - 主程序（双击运行）
app/                   - 程序文件（不要删除）
runtime/               - Java运行环境（不要删除）

注意：整个文件夹需要保持完整，不要单独移动 exe 文件
